# 🎨 Desktop Environment: Niri & DankMaterialShell (DMS)

This document describes the architecture of the workstation's graphical desktop environment, the boundary between declarative configuration and runtime state, and the master shortcut reference.

---

## 2. The Ownership & Mutability Boundary

A critical architectural invariant is respecting the distinction between **declarative specification** and **runtime-mutable state**:

| Layer | Files | Managed By Git? | Mutability | Rationale |
| :--- | :--- | :--- | :--- | :--- |
| **Declarative Core** | `home/config/niri/config.kdl`<br/>`home/config/niri/custom.kdl` | **Yes** | Immutable store symlinks | Governs compositor rules, gesture bindings, and personal shortcuts. |
| **System Daemon** | `system/desktop.nix` | **Yes** | Immutable NixOS module | Enables Niri, DMS package, Greetd greeter, fonts. |
| **DMS Niri IPC Bindings** | `~/.config/niri/dms/binds.kdl` | **No** (Bootstrap-owned) | Mutable (`0644`) | Initialized via `dms setup binds`. Bridges Niri to DMS runtime controls; editable via GUI/CLI. |
| **DMS UI Preferences** | `~/.config/DankMaterialShell/settings.json` | **No** | Mutable | Stores user's bar widget selections, padding, and corner radius. |
| **Display Outputs** | `~/.config/niri/dms/outputs.kdl` | **No** | Dynamic runtime | Generated by DMS when external displays are connected/repositioned. |
| **Color Schemes** | `~/.config/niri/dms/colors.kdl` | **No** | Dynamic runtime | Extracted by Matugen from the active wallpaper. |

> [!IMPORTANT]
> `binds.kdl` is not part of the declarative workstation configuration. It is a bootstrap-owned artifact whose initial contents are established by `dms setup binds`. It serves as the bridge between Niri and DMS's runtime controls (the DMS-managed Niri IPC integration bindings). An empty or missing file disconnects a substantial portion of the desktop's control surface.

> [!CAUTION]
> Do not attempt to manage `~/.config/niri/dms/` or `~/.config/DankMaterialShell/settings.json` via Home Manager store symlinks. Doing so breaks DMS's runtime ability to persist display changes, theme updates, and interactive settings.

## 3. Desktop Initialization (Fresh User Profile)

On a fresh user profile (or after recreating `$HOME`), initialize the mutable baseline keybindings with:

```bash
dms setup binds
```

This ensures `~/.config/niri/dms/binds.kdl` is created with proper user write permissions (`0644`) before Niri loads.

## 4. Master Shortcut Reference

> [!NOTE]
> **Precedence Rule**: In `config.kdl`, `include "custom.kdl"` is evaluated *after* `include optional=true "dms/binds.kdl"`. Where key definitions collide, `custom.kdl` overrides DMS defaults. Specifically:
> - `Mod+O` launches Obsidian (overriding DMS's secondary overview shortcut; toggle overview via `Mod+Tab`).
> - `Mod+W` triggers area screen recording (overriding DMS's column tabbed display toggle).

### Core Applications & Session
| Shortcut | Action | Source | Precedence Note |
| :--- | :--- | :--- | :--- |
| `Mod+Return` | Open Alacritty Terminal | Custom (`custom.kdl`) | Primary workstation terminal. |
| `Mod+T` | Open Terminal | DMS IPC (`binds.kdl`) | Alternative terminal launcher. |
| `Mod+B` | Launch Firefox Browser | Custom (`custom.kdl`) | Browser shortcut. |
| `Mod+O` | Launch Obsidian Notes | Custom (`custom.kdl`) | Overrides DMS `Mod+O` overview. |
| `Mod+Tab` | Toggle Niri Column Overview | DMS IPC (`binds.kdl`) | Primary overview trigger. |
| `Mod+Space` / `Alt+Space` | Toggle Spotlight Application Launcher | DMS IPC (`binds.kdl`) | DMS app launcher modal. |
| `Mod+V` | Toggle Clipboard Manager | DMS IPC (`binds.kdl`) | DMS clipboard history modal. |
| `Mod+M` | Toggle Task Manager / Process List | DMS IPC (`binds.kdl`) | DMS process manager. |
| `Super+X` | Toggle Power Menu (Lock / Suspend / Shutdown) | DMS IPC (`binds.kdl`) | DMS session menu. |
| `Mod+Comma` | Open DMS Settings Modal | DMS IPC (`binds.kdl`) | Interactive desktop settings. |
| `Mod+Shift+E` | Quit Niri Session | Niri Native (`binds.kdl`) | Exits Wayland compositor. |
